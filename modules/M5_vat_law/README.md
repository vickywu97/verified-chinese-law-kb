## 数据格式

`statutes.jsonl` 每行一个 JSON 对象，字段如下（**已省略具名签署字段 `verified_by`**）：

| 字段 | 说明 |
|------|------|
| `id` | 条文唯一 ID，格式 `{law_code}_{sort_key}_v1` |
| `law_code` | 法律代码，本模块为 `VAT_LAW` |
| `article_number` | 条文编号（中文，如 `第1条`） |
| `article_sort_key` | 条文排序键（整数） |
| `content` | 条文原文（已核验） |
| `effective_date` | 施行日期 `2026-01-01` |
| `revision_of` | 修订自（无则为 `null`） |
| `verification_status` | `verified` |
| `verified_at` | 核验日期（ISO） |
| `source_url` | 官方来源链接 |
| `source_accessed_at` | 源访问日期 |
| `notes` | 备注（如修订要点） |

配套 `verifications.json` 以条文 ID 为键，记录 `status` / `verified_at` / `source` / `notes`，不含署名。

## 核验说明

- 条文原文逐条比对官方公报（全国人民代表大会常务委员会公报 / 官方法律法规数据库），核验状态为 `verified`。
