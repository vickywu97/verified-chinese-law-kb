## 数据格式

`statutes.jsonl` 每行一个 JSON 对象，字段如下（**已省略具名签署字段 `verified_by`**）：

| 字段 | 说明 |
|------|------|
| `id` | 条文唯一 ID，格式 `{law_code}_{sort_key}_v1`（补充条文 sort_key 含小数，如 `CRIMINAL_LAW_17.001_v1`） |
| `law_code` | 法律代码，本模块为 `CRIMINAL_LAW` |
| `article_number` | 条文编号（中文，如 `第1条`、`第17条之一`） |
| `article_sort_key` | 条文排序键（整数或小数；小数用于「之一 / 之二」等补充条文，保证与相邻正文相邻排序） |
| `content` | 条文原文（已核验） |
| `effective_date` | 施行 / 修正日期（`1997-10-01` 或 `2024-03-01`） |
| `revision_of` | 修订自（无则为 `null`） |
| `verification_status` | `verified` |
| `verified_at` | 核验日期（ISO） |
| `source_url` | 官方来源链接 |
| `source_accessed_at` | 源访问日期 |
| `notes` | 备注（如修订要点） |

配套 `verifications.json` 以条文 ID 为键，记录 `status` / `verified_at` / `source` / `notes`，不含署名。
