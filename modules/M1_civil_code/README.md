# 模块 M1 · 民法典（Civil Code）

## 法律简介

《中华人民共和国民法典》于 2020-05-28 由全国人民代表大会通过，自 **2021-01-01** 起施行，
是新中国第一部以「法典」命名的法律，共 7 编 1260 条，整合了原《合同法》《物权法》《婚姻法》
《继承法》《侵权责任法》《民法总则》等，并新增了人格权编。

- 制定机关：全国人民代表大会
- 生效日期：2021-01-01
- 官方来源：[全国人大公报 flk.npc.gov.cn](https://flk.npc.gov.cn/detail2.html?ZmY4MDgxODE3OTZhNjM2YTAxNzc4MmYyMGRiYTk3ZWY%3D)

- **版本固定**：当前仅收录 2021-01-01 生效版本；若后续有修正，将新增 `revision_of` 版本并记入本文件 CHANGELOG。
