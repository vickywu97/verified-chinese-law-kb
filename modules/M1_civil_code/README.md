# M1 · 中华人民共和国民法典

> 模块化法条知识库子模块。**每一条条文均为已核验原文**，来源为官方公报。本模块为仓库首发模块，保留具名签署（与 M3 起「仅保留已核验原文、不具名签署」的约定不同，M1 为特例）。

## 条文统计

本模块收录**全部 1260 条**已核验条文（完整民法典文本，2021-01-01 施行），条文连续编号第 1 条至第 1260 条，无缺号、无「之一 / 之二」补充条文。

`verification_status` 均为 `verified`。完整条文以 `statutes.jsonl` 为准。

## 数据格式

`statutes.jsonl` 每行一个 JSON 对象，字段如下（**本模块保留具名签署字段 `verified_by`**，为仓库特例；其余模块自 M3 起省略该字段）：

| 字段 | 说明 |
|------|------|
| `id` | 条文唯一 ID，格式 `{law_code}_{sort_key}_v1` |
| `law_code` | 法律代码，本模块为 `CIVIL_CODE` |
| `article_number` | 条文编号（中文，如 `第1条`） |
| `article_sort_key` | 条文排序键（整数） |
| `content` | 条文原文（已核验） |
| `effective_date` | 施行日期（`2021-01-01`） |
| `revision_of` | 修订自（无则为 `null`） |
| `verification_status` | `verified` |
| `verified_at` | 核验日期（ISO） |
| `verified_by` | 具名签署人（仅本模块保留）：`Vicky Wu (律师/税务师/专利代理师)` |
| `source_url` | 官方来源链接 |
| `source_accessed_at` | 源访问日期 |
| `notes` | 备注（如立法目的） |

配套 `verifications.json` 以条文 ID 为键，记录 `status` / `verified_at` / `source` / `verified_by` / `notes`。

## 核验说明

- 条文原文逐条比对官方公报（全国人民代表大会公报 / 官方法律法规数据库），核验状态为 `verified`。
- 本模块为仓库首发模块，按早期约定保留具名签署；自 M3 起的新模块遵循「仅保留已核验原文、不具名签署」的统一约定。

## 版本与修订

- 民法典于 2020-05-28 通过，2021-01-01 施行，是新中国成立以来第一部以「法典」命名的法律，整合了原《婚姻法》《继承法》《民法通则》《收养法》《担保法》《合同法》《物权法》《侵权责任法》等。
